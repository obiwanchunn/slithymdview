# SlithyMDView

A no-bloat Markdown (`.md`) viewer and editor — formerly **MdView**. Open a file and it's shown
fully formatted; flip to **Edit** for the raw text with the markup styled as you type. **Markup**
reveals every piece of markup (like Word's ¶ button), and the **cheat sheet** lists every
Markdown construct with an *Insert* button. Obsidian-style wiki links work too: `[[#Heading]]`
jumps within the file, `[[Other note]]` opens `Other note.md` from the same folder (Windows), and
`[[target|text]]` sets the link text.

*'Twas brillig, and the slithy toves / Did gyre and gimble in the wabe.*

> **Why is the iPhone app in a folder called `docs`?** GitHub Pages' simple "Deploy from a
> branch" setting can only publish the top of the repo or a folder named exactly `docs`. So the
> iPhone app lives in `docs/` even though it isn't documentation. Pages setting:
> **Settings → Pages → Deploy from a branch → `main` → `/docs`**. Don't rename the folder.
> Don't edit `docs/` by hand either — it's generated by the build below.

## iPhone

Published from `docs/` with GitHub Pages: **https://obiwanchunn.github.io/slithymdview/**

1. Open that link in **Safari** on the iPhone.
2. **Share** → **Add to Home Screen** → **Add**.
3. Open SlithyMDView from the Home Screen.

- **Open** (folder button) picks a `.md` file from the Files app.
- **Save** hands a copy back through the share sheet — choose **Save to Files** and pick the
  folder (and replace the old file if you like). A web app can't write over the original directly.
- Unsaved edits are kept as a draft, so nothing is lost if iOS closes the app; they come back the
  next time you open it.
- Images referenced by a relative path (`![](images/x.png)`) don't show on the phone — a web app
  can only see the one file you opened. Web images (`https://…`) do.
- Split view is hidden on phone-width screens; View/Edit, Markup and the cheat sheet all work.
- Everything happens on the phone; documents are never uploaded.

## Windows

See [`windows/README.md`](windows/README.md). In short: install the .NET 10 SDK, run
`windows\build.cmd`, open `windows\publish\SlithyMDView.exe`, then **⋯ → Use SlithyMDView for .md
files…**. Coming from MdView: run `MdView.exe --unregister` once to remove the old entries.

## Changing the screen (both versions)

The UI lives in `web-src/` and is shared. After editing it (needs Node.js 18+):

```
cd web-src
npm install
npm run build
```

That regenerates `windows/SlithyMDView/web/` (embedded in the exe — rebuild the exe) and `docs/`
(the iPhone app — push to publish). `src/host.js` is the only part that differs: on Windows it
talks to the exe; on iPhone it opens/saves through the browser. Versions: iPhone in
`web-src/build.mjs` (`IPHONE_VERSION`), Windows in `windows/SlithyMDView/SlithyMDView.csproj`.

The icon (the SlithyLens tove leaning over a Markdown page) is generated by `web-src/art/make_icon.py`.
