# This folder is the SlithyMDView iPhone app (not documentation)

GitHub Pages publishes this folder as the website **https://obiwanchunn.github.io/SlithyMDView/**.
It's named `docs` only because Pages' simple setting can publish just the repo's top level or a
folder called exactly `docs` (Settings → Pages → Deploy from a branch → `main` → `/docs`).
Don't rename it, or the site stops updating.

Don't edit the files here by hand either: they're generated from `web-src/` by
`npm run build` (see the [main README](../README.md)).
